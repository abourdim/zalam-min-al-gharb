# ظلام من الغرب — Darkness from the West

Interactive trilingual web app based on **"Zalam min al-Gharb"** (Darkness from the West) by **Sheikh Mohammed al-Ghazali** (1917-1996).

## About the Book

256 pages, 20 chapters. Sheikh al-Ghazali responds to Orientalists and Westernization advocates, exposing "Arab Orientalists" — Muslims who repeat Western anti-Islam rhetoric without verification. Topics include: sources of sin, mind vs emotion, law of causality, Arabism of Islam, colonial schemes, cultural invasion in legislation, modern jahiliyya, protecting morals, nations between growth and decay, toward Islamic unity, and where to direct our culture.

## Features

- **Trilingual**: Arabic, English, French
- **20 Analysis Cards**: Light vs Darkness — comparing Islamic values with Western critiques
- **Critical Thinking Quiz**: 15 questions with lifelines (50/50, Ask the Sheikh)
- **Compare Tab**: Side-by-side claim vs reality comparisons
- **XP & Badges**: Gamification with 5 badge levels
- **Narrator**: Full audiobook narrator with karaoke, speed/pitch controls, sleep timer, duo reading
- **3 Themes**: Charcoal, Moonlight, Dawn
- **PWA**: Installable progressive web app
- **Kids-Friendly**: Age mode toggle (Young Explorer / Teen Scholar)

## Tech

Pure HTML/CSS/JS — no frameworks, no build tools. Uses Web Audio API for sound effects and Web Speech API for narrator.
